# Component: i18n (Internationalization)

## Responsibility

Locale-aware formatting, language selection, and translation string
management for the AikiField.com site. Only `en` and `es` are live;
other locales are stubs.

## Files

| File | Role |
|------|------|
| `data/i18n-config.json` | Locale config: supportedLocales, localeNames, rtlLocales, currency, timezone |
| `data/i18n-strings/<locale>.json` | 844 translation keys per locale (12 locales, 1116 lines each) |
| `data/i18n-glossary.json` | Translation glossary |
| `data/translations/es.json` | Spanish translations |
| `js/locale-utils.js` | `AFLocale` global; Intl API wrappers; locale detection/persistence; RTL (~507 lines) |
| `js/language-selector.js` | `<select>`-based language switcher; depends on `locale-utils.js` (~96 lines) |
| `scripts/extract_i18n_strings.py` | Extract translatable strings from HTML |
| `scripts/translate-strings.py` | Translate strings via Google Cloud Translation API |
| `scripts/generate_locale_files.py` | Generate locale files |
| `scripts/apply_i18n_attrs.py` | Apply i18n attributes to HTML |
| `scripts/tag-untranslated-text.py` | Tag untranslated text |
| `assets/i18n/<locale>/*.svg` | Localized SVG diagrams (3 per locale) |

## Interfaces

### Inbound (browser)

- `js/locale-utils.js` fetches `/data/i18n-config.json` and
  `/data/i18n-strings/<locale>.json`
- `js/language-selector.js` auto-mounts into `#af-language-selector` or
  `[data-af-language-selector]`

### Outbound

- `scripts/translate-strings.py` → Google Cloud Translation API
  (INFERRED — no API key in repo)

## Dependencies

- **Config:** `data/i18n-config.json` (runtime), Google Cloud
  Translation API (scripts only)
- **Runtime:** Browser Intl APIs (NumberFormat, DateTimeFormat,
  RelativeTimeFormat), `fetch()`
- **No build step:** plain `<script>` tags; no module bundler

## Consumers

- All public HTML pages (language selector in nav/footer)
- `assets/i18n/<locale>/*.svg` — localized diagrams

## State/data

- Browser localStorage: `af_locale` key (locale persistence)
- No server-side state

## Supported locales (OBSERVED)

- **Live:** `en` (English), `es` (Español)
- **Stubs (not offered in UI):** `fr` (Français), `de` (Deutsch), `pt`
  (Português), `ja` (日本語), `zh` (中文), `ko` (한국어), `ar` (العربية),
  `he` (עברית), `fa` (فارسی), `hi` (हिन्दी)
- **RTL:** `ar`, `he`, `fa` — applied via `[dir="rtl"]` on `<html>`

## Conventions (OBSERVED)

- Native (endonym) names, not flags (flags represent nations, can be
  politically sensitive — DECLARED: issue #76)
- `<select>`-based selector for keyboard accessibility (DECLARED: issue
  #81)
- `aria-live` region announces language changes
- Text expansion factor: 0.4 (translations can be 30-40% longer)
- UTC internally; formatted to user's timezone on display
