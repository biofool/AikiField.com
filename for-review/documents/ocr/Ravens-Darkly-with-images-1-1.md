Ravens Darkly

Haiku means playful verse. I write in the Zen Haiku tradition.
Each of the poems found here reflect a direct experience in
Nature in which the poet disappears into the suchness of what’s
arising in the now.

      To the One within All.
|     |     |     |     |     |     |
| --- | --- | --- | --- | --- | --- |
|     |     |     |     |     |     |

|     |     |     |     |     |     |
| --- | --- | --- | --- | --- | --- |

|     |     |     | Grey dawn. . .                          |                    |     |
| --- | --- | --- | --------------------------------------- | ------------------ | --- |
|     |     |     |   ravens croaking darkly to each other  |                    |     |
|     |     |     |                                         | above the forest.  |     |

|     |     |     | No wind in the silent green hemlocks. . .  |                 |
| --- | --- | --- | ------------------------------------------ | --------------- |
|     |     |     |   just the sound of unseen                 |                 |
|     |     |     |                                            | raven’s wings.  |

|     |     |     |     |     |
| --- | --- | --- | --- | --- |
Sunlight breaks through the clouds. . .
revealing dew
sparkling
|              |       |     |     |   in tangled grasses.   |
| ------------ | ----- | --- | --- | ----------------------- |

Crystal dew
glistening in sunlight. . .
just dissolves
completely away.

|     |     |     | With each step that glossy raven  |                    |     |     |
| --- | --- | --- | --------------------------------- | ------------------ | --- | --- |
|     |     |     |   thrusts his great beak          |                    |     |     |
|     |     |     |                                   |   into the world.  |     |     |
|     |     |     |                                   |                    |     |     |

Eagles dancing in midair. . .
yellow talons reach
for yellow talons.

|     |     |     |     |     |     |
| --- | --- | --- | --- | --- | --- |
|     |     |     |     |     |     |

The graceful tip
|     |     |     |     |   of the that towering hemlock tree  |                    |
| --- | --- | --- | --- | ------------------------------------ | ------------------ |
|     |     |     |     |                                      | simply bows over.  |

|     |     |     |     |     |
| --- | --- | --- | --- | --- |

Suddenly in sunlight,
      hundreds of ants
                 floating
|     |     |            |     | on translucent wings.  |
| --- | --- | ---------- | --- | ---------------------- |

That sunlit blue dragonfly. . .
changes her direction
in an instant !

|     |     |     |     |     |
| --- | --- | --- | --- | --- |
Duck pops up on the pond’s smooth surface
|     |     |     |     | rippling out           |
| --- | --- | --- | --- | ---------------------- |
|     |     |     |     |   concentric circles.  |

|     |     |   A glimpse of black wasp startles me !  |     |
| --- | --- | ---------------------------------------- | --- |
  startling
|     |     |         |       the yellow banded wasp.   |
| --- | --- | ------- | ------------------------------- |

|     |     |     |     |
| --- | --- | --- | --- |

|     |     |     | Windy. . .a seed sail            |
| --- | --- | --- | -------------------------------- |
|     |     |     |   caught in this spider’s web    |
|     |     |     |     is shaking the whole thing.  |

|     |     |     | On a slender strand of invisible silk,   |                       |
| --- | --- | --- | ---------------------------------------- | --------------------- |
|     |     |     |           spider                         |                       |
|     |     |     |                                          | climbs the blue sky.  |

Surrounded by swaying forest. . .
chirpling birds hide
in sudden silence.

High in the swinging fir. . .
eagle screeching out
into empty blue.

Yielding to supple wind,
each green fir dancing gracefully
with the Divine.

Clear autumn night. . .
|      |     |        |     high winds have scattered the stars  |                            |
| ---- | --- | ------ | ---------------------------------------- | -------------------------- |
|      |     |        |                                          |    across the hollow sky.  |

|                       |     |      |     |
| --------------------- | --- | ---- | --- |

For thirty years I have been
in search of the Swordsman;
Many a time I have watched
the leaves decay and the branches shoot;
Ever since I saw for once
the peaches in bloom,
Not a shadow of a doubt
do I cherish.
--Ling Yun
